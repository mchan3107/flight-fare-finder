# Flight Fare Finder

build a SaaS landing page + authenticated app shell for flight price notifier, a product that watches popular flight routes from San Jose and emails the user when the cheapest fare drops to or below their target price -targeted at budget-driven travelers who don't care exactly when to fly, they just want a ticket under their budget. The site must include: a public landing page(/) with Hero section: product name "Flight price notifier" prominently displayed, value drop (set a route and a target price, we email you when the fare drops), and a primary CTA button labeled "Sign in" in the top right header
